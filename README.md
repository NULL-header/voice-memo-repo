# Voice Memo Repository

音声入力で作成されたメモを整理し、清書済みドキュメントとして管理するためのリポジトリです。

## 前提

このリポジトリの処理フローは、日本語の音声入力テキストを前提に組まれています。誤字、誤変換、どもり、繰り返しなども日本語の文脈に基づいて判断します。

想定フローでは、Windows標準の音声入力利用を使っています。

動作確認は、VSCodeのCodex拡張上でのみ行っています。

## 使い方

1. `tmp.md.sample` の `sample` 拡張子を消して `tmp.md` にします。
2. `tmp.md` に音声入力テキストを入れます。
3. `run-voice-memo-flow` を実行します。

## 入力

- `tmp.md`: 音声入力データ

## 出力

- `refined/{timestamp}.md`: `tmp.md` を元に内容を整理した清書データ

## 各コマンドについて

- `run-voice-memo-flow`
  - 通常利用するメインコマンドです。
  - `tmp.md` を読み取り、ノイズ除去済みの一時ファイル `clean.md` を生成します。
  - `clean.md` を元に、UTC タイムスタンプ付きの新しい `refined/{timestamp}.md` を作成します。
  - 清書ファイルの作成が成功したことを確認してから、`clean.md` を削除し、`tmp.md` を空にします。
  - 途中で失敗した場合や結果を確認できない場合は、後続処理を止め、`tmp.md` や `clean.md` を残します。
- `answer-from-refined`
  - `refined/*.md` に保存された清書済みメモを情報源として、質問に回答するためのコマンドです。
  - 回答時は `refined/` 配下の Markdown ファイルだけを検索、参照します。
  - `tmp.md`、`clean.md`、README、Web検索、一般知識などは根拠として使いません。
  - `refined/*.md` 内に根拠がない場合は、推測せず、回答に必要な情報がないことを伝えます。
- 上記で解説されていないコマンドの直接実行は想定していません。
- 詳細は `.agents/skills/` を参照してください。
