# Voice Memo Repository

音声入力で作成されたメモを整理し、清書済みドキュメントとして管理するためのリポジトリです。

## 前提

このリポジトリの処理フローは、日本語の音声入力テキストを前提に組まれています。誤字、誤変換、どもり、繰り返しなども日本語の文脈に基づいて判断します。

想定フローでは、Windows標準の音声入力利用を使っています。

動作確認は、VSCodeのCodex拡張上でのみ行っています。

## 使い方

1. `tmp.md.sample` の `sample` 拡張子を消して `tmp.md` にします。
2. `tmp.md` に音声入力テキストを入れます。
3. `run-voice-memo-flow` を実行します。

## 入力

- `tmp.md`: 音声入力データ

## 出力

- `refined/{timestamp}.md`: `tmp.md` を元に内容を整理した清書データ

## 各コマンドについて

- `run-voice-memo-flow` 以外は直接実行を想定していません。
- 詳細は `.agents/skills/` を参照してください。
